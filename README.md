# Certified Penetration Tester Specialist (CPTS) Study Notes

Structured penetration testing methodologies, cheat sheets, and technical notes aligned with the Hack The Box CPTS certification path.

## Methodology & Repository Structure

The contents follow standard penetration testing execution phases:

1. `Pre-Engagement/`: Scoping, rules of engagement, and environment setup.
2. `Information Gathering/`: Active and passive reconnaissance, OSINT, network and port enumeration.
3. `Vulnerability Assessment/`: Service analysis, vulnerability identification, and flaw validation.
4. `Exploitation/`: Web-based attacks, public exploits, and initial foothold acquisition.
5. `Privilege Escalation/`: Linux and Windows local elevation vectors and credential harvesting.
6. `Attacking Enterprise Networks/`: Lateral movement, pivoting, tunneling, and Active Directory exploitation.
7. `Documentation/`: Engagement reporting, evidence collection, and remediation guidance.
