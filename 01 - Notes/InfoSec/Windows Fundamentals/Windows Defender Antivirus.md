## Windows Defender Antivirus

- Windows Defender Antivirus: built-in security solution for Windows operating systems

- Key features:
	- Real-time protection: ==Continuously== scans for known threats and blocks malicious activity in real-time.
	- Cloud-Delivered Protection: ==Uploads== suspicious files to Microsoft's ==cloud== for analysis and blocks potential threats before execution
		- When uploading, the file is locked until the analysis is completed
	- Tamper Protection: ==Prevents unauthorized changes== to security settings via Registry, PowerShell, or Group Policy.
	- Controlled Folder Access (Ransomware Protection): B==locks unauthorized programs== from modifying protected files and folders.

- Lightweight vs other antivirus software
