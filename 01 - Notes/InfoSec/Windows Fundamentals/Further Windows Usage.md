## Microsoft Management Console (MMC)

- **Microsoft Management Console (MMC)** is a framework for ==grouping administrative tools==—known as snap-ins—to manage hardware, software, and network components on Windows systems

- To create customized consoles tailored to managing specific services on both local and remote systems

- Typing `mmc` in the Start menu, then see the link for more


## Windows Subsystem for Linux (WSL)

- WSL enables ==running Linux binaries== directly on Windows 10 and Windows Server 2019

- To run Bash, Ruby in Windows

- Installed by running the PowerShell command `Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux`

- Type `bash` to pop a Bash window up

- Access the C$ volume and other volumes on the host operating system via the ==mnt== directory
