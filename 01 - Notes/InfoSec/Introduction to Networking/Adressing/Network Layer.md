## Network Layer

- **Network Layer** (L3 of OSI): responsible for **routing data packets** across networks from a source to a destination, often through ==multiple intermediate nodes== (routers)

- Key **Functions**:
	- Logical addressing (assign IP address)
	- Routing (determine the path through nodes)

- Common **Protocols**:
	- **IPv4/IPv6** – Addressing and routing
	- **IPsec** – Secure IP communication
	- **ICMP** – Error messaging and diagnostics
	- **IGMP** – Multicast group management
	- **RIP, OSPF** – Dynamic routing protocols
