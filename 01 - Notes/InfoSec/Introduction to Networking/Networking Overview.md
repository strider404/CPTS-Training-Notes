## Networking Overview


![[Pasted image 20250424102726.png]]


- **URL** (Uniform Resource Locator) vs **FQDN** (Fully Qualified Domain Name):
	- **FQDN (e.g., [www.hackthebox.eu](http://www.hackthebox.eu))** identifies the main address (the "building").
	- **URL (e.g., [https://www.hackthebox.eu/example?floor=2&office=dev&employee=17](https://www.hackthebox.eu/example?floor=2&office=dev&employee=17))** includes specific directions within that address (like "floor," "office," etc.).

- **Connect from home -> company**:
	- PC (sending packets) -> Home Router (local post office) -> ISP (Internet Service Provider) (main post office) Use DNS (Domain Name Service) (like a phonebook) to resolve the FQDN into an IP address (the exact geographic location) -> Company Web server
