# VPS

1. `Virtual Private Server` (`VPS`) is an isolated environment on physical server using virtualization tech

2. Part of the IaaS (Infrastructure-as-a-Service)

3. Freedom, can allocate resources and can use the OS or software we want without configuration restrictions; has various functions just like dedicated server (physical server)

4. `Virtual Dedicated Server` (`VDS`): physical server of the VPS

5. Is a compromise between dedicated server and inexpensive shared hosting
