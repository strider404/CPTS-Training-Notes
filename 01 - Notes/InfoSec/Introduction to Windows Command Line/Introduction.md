## Command Prompt Vs. PowerShell

- **PowerShell** (introduced in 2006) is more ==advanced==, supporting scripting, cmdlets, object-based output, and access to .NET libraries.

- **Command Prompt** (introduced in 1981) is more ==limited==, supporting only batch commands and text-based output.

- **PowerShell** can execute both batch commands and PowerShell cmdlets, while Command Prompt is restricted to batch commands.
