## Bourne Again Shell

- **The Bourne Again Shell (Bash)** is an *interpreted scripting language* used to issue commands to Unix-based operating systems.

- Bash scripts possess a structure analogous to programming languages, incorporating elements such as variables, arrays, conditional statements (`if-else`, `case`), loops (`for`, `while`), and functions.
  
- Scripts are processed by an interpreter. They can be executed using commands like `bash script.sh` or directly via `./script.sh` if the file has execute permissions.
