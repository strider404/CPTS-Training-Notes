## Enumeration

- It is the process of **gathering information** about a target using both **active** methods (like network scans) and **passive** methods (like using third-party data).

## OSINT

- Enumeration is distinct from Open-Source Intelligence (OSINT).

- OSINT is exclusively passive information gathering, whereas enumeration includes active engagement with the target.
