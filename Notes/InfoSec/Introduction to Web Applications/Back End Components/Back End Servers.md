## Back End Servers

- **Core Function:** A back-end server comprises the *hardware* and *operating system* that hosts and executes all applications and processes for a web application. It is considered part of the **Data Access Layer**.

## Components

- **Essentials**:
	- Web server
	- Database
	- Development framework

- **Additional**:
	- Hypervisors
	- Containers
	- Web Application Firewalls (WAFs)

- **Common Stacks:** Specific combinations of back-end components, known as "stacks," are common. Examples include:
	- **LAMP:** Linux, Apache, MySQL, PHP
    
	- **WAMP:** Windows, Apache, MySQL, PHP
    
	- **MAMP:** macOS, Apache, MySQL, PHP
    
	- **WINS:** Windows, IIS, .NET, SQL Server
    
	- **XAMPP:** Cross-Platform, Apache, MySQL, PHP/Perl

- **Hardware and Architecture:**
	- The server's hardware specifications directly impact the web application's performance and stability.
	  
		- Large-scale applications often distribute their workload across **multiple servers.**
		  
	- These servers can be physical machines or virtual hosts provided by data centers and cloud hosting services.
