## JavaScript

- **JavaScript** is a widely-used programming language primarily for **web and mobile development**.

- It adds **functionality and interactivity** to web pages, which would otherwise be static if only using HTML (for structure) and CSS (for style).

- It can be used for **both** **front-end** (running in the browser) and **back-end** (e.g., NodeJS) development.


#### Implementation & Execution

- JavaScript code is **embedded into HTML** using the `<script>` tag, either directly or by linking to an external `.js` file.

- All modern web browsers contain **JavaScript engines** that *execute the code on the client's machine*, allowing for rapid updates without needing to contact the server

- **Example**:
	- `<script type="text/javascript">`
		`..JavaScript code..`
		`</script>`
		
	- `<script src="./script.js"></script>`

#### Common Applications

- Updating web page content in **real-time.**
  
- Processing **user input** from forms and other elements.
  
- **Performing HTTP requests** (e.g., via Ajax) to send and receive data from a server.
  
- **Creating complex animations** in conjunction with CSS.

#### Frameworks

- These frameworks provide **pre-built libraries** and tools to simplify common tasks like user authentication and dynamic content management.

- Prominent examples include **Angular, React, Vue, and jQuery**.
