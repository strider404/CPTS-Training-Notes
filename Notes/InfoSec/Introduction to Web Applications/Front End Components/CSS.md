## CSS

- **CSS**, or **Cascading Style Sheets**, is a *stylesheet language* used with HTML to define the *visual* formatting and style of web page elements.

- **It operates in versions,** with each new version introducing more capabilities, which modern browsers are updated to support.

- CSS rules are defined for a selector (HTML element, class, or ID) within **curly brackets** `{}`: `element { property : value; }`

- **Example**:
	- `body {`
	  `background-color: black;`
		`}`

- It is frequently used in conjunction with **JavaScript** to dynamically modify styles *based on user interactions* (e.g., key presses, mouse movement) or calculations.

- **Frameworks**:
	- These frameworks (e.g., Bootstrap, SASS, Foundation) provide *pre-written collections of CSS stylesheets and designs*, accelerating web development.
