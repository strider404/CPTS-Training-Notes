# Virtualization

1. "`Virtualization` is an ==abstraction of physical computing resources== (both hardware and software)"

	It means you can create a virtual representations of CPUs, GPUs, software,...etc and make it work just like the real counterparts. 

2. "The main advantage of virtualization is the abstraction layer between the physical resource and the virtual image."

	if you use VMware then VMware is the abstraction layer

3. Aim: 
	-  to make these resources available on a virtual level and to distribute them to different customers in a manner that is as flexible as it is demand-driven
	
	-  to run applications on a system that is not supported (ex: want to run an app on Linux but you don't want to uninstall Windows either,...)

4. Types:

	- Hardware virtualization (through hypervisor) [[Virtual machines]]
    
	- Application virtualization (through containers) [[01 - Notes/InfoSec/Setting up/Containers]]
    
	- Storage virtualization
    
	- Data virtualization
    
	- Network virtualization
