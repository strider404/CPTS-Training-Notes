## Plugins

- **Plugins**: Wireshark's advanced functionalities are largely powered by a wide range of plugins available through the **Analyze** and **Statistics** tabs.

- **Statistics Tab**: This tab provides plugins that offer *deep insights* into the captured network data.

- **Analyze Tab**: This tab allows users to:
	- Follow protocol streams (e.g., TCP).
	  
	- Filter conversations.
	  
	- Create new display filters.
	  
	- Review expert information generated by Wireshark.


#### Following TCP Streams

- **Functionality**: Wireshark can reassemble TCP packets to *reconstruct the complete data stream* in a human-readable format. This is essential for viewing entire conversations and extracting embedded data like images and files.

- Select 1 TCP packet, go to Analyze tab -> Follow TCP Stream -> that will display all the packet stream of that conversation

#### Extracting Data and Files from a Capture

- **Prerequisite**: The entire data conversation must be present in the capture file for successful extraction.

- **General Extraction Method**:
    - Stop the packet capture.
    - Go to `File → Export Objects → [Protocol]`.
    - Select the appropriate protocol (e.g., HTTP, SMB, DICOM) to extract files transferred over it.


#### FTP Disector

- **Background**: File Transfer Protocol (FTP) uses TCP as its transport protocol.
	- **Port 21**: The control port, used for commands like login, listing files (`ls`), and initiating transfers (`get`, `put`).
	- **Port 20**: The data port, used for the actual file transfer.

- **Useful FTP Display Filters**:
	- `ftp`: Displays all *FTP-related traffic*.
	- `ftp.request.command`: Shows commands sent over the *control port (21)*, which can *reveal usernames, passwords, and requested filenames.*
	- `ftp-data`: Isolates the data transferred over the *data port (20)*.

- **Steps to Extract Files from FTP**:
    - Identify FTP traffic using the `ftp` filter.
    - Use the `ftp.request.command` filter to find interesting commands and identify which files were transferred.
    - Filter for `ftp-data` and select a packet corresponding to the file of interest.
    - Follow the associated TCP stream for that file transfer.
    - In the stream window, change the view to "Raw" data.
    - Save the raw data as a new file, giving it the original filename.
    - Verify the file integrity.
