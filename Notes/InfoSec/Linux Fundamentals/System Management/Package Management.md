## Packages and Package Management

- Packages are archives that contain binaries, config files, info about dependencies & keep track of updates

- Package management software retrieves the necessary changes for system installation from the package itself and then implements these changes to install the package successfully

- Is integrated directly under the system

## Advanced Package Manager (APT)

- In Debian, packages contains .deb files, and *dpkg* is used to install those programs from .deb files

- *APT* makes it easier because those files has dependencies, u may need to install 1 or more additional packages to make the program runs error-free, and the APT packaging them together to install at once

- APT cache is used to provide info about packages in the system
