## Prompt Description

- Default prompt: `<username>@<hostname><current working directory>$`

- Home directory: '~'

- PS1 variable controls how ur prompt looks in the terminal. Can customize it to show basic infos or something more advanced like IP address, the last section success or fail, date & time,...

- If not customize the PS1 variable, it will look like this:
	- Unprivileged: `$`
	- Privileged: `#`
