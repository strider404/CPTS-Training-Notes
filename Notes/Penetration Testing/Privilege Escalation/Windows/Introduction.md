## Introduction

- **Primary Goal:** Escalate access from an initial foothold to a Local Administrator or the `NT AUTHORITY\SYSTEM` account.


- **Common Objectives:** Assess gold/workstation images, access restricted local resources (like databases), pivot into an Active Directory environment, or gather credentials for lateral movement.


- **Attack Surface:** Includes abusing group/user privileges, bypassing User Account Control (UAC), exploiting weak file/service permissions, leveraging unpatched kernels, and credential theft.


- **Underlying Causes:** Often stems from budget or personnel constraints, which lead to poor patch management, lack of continuous monitoring, and un-audited file shares.


- **Manual Enumeration:** Essential skill when automated tools cannot be transferred to highly restricted, firewalled, or isolated environments.
