## Automating Recon

- Automating reconnaissance is **more efficient and accurate** than manual methods. It allows for gathering information at a larger scale and identifying vulnerabilities more quickly.


## Reconnaissance Frameworks

- **FinalRecon**: A modular Python tool for tasks like SSL checks, Whois lookups, header analysis, and crawling.
  
- **Recon-ng**: A powerful, modular Python framework for DNS enumeration, port scanning, and web crawling.
  
- **theHarvester**: Gathers email addresses, subdomains, hosts, and open ports from public sources.
  
- **SpiderFoot**: An open-source intelligence (OSINT) automation tool that collects information from various data sources.
  
- **OSINT Framework**: A collection of tools and resources for OSINT gathering.


## FinalRecon

- **Key Features**:
	- **Header Information**: Reveals server details and technologies.
    
	- **Whois Lookup**: Provides domain registration details.
    
	- **SSL Certificate Information**: Examines SSL/TLS certificate details.
    
	- **Crawler**: Extracts links and resources from HTML, CSS, and JavaScript.
    
	- **DNS Enumeration**: Queries over 40 DNS record types.
    
	- **Subdomain Enumeration**: Uses multiple sources like `crt.sh` and various APIs to find subdomains.
    
	- **Directory Enumeration**: Uncovers hidden directories and files using wordlists.
    
	- **Wayback Machine**: Retrieves historical URLs to analyze website changes.
