## WHOIS

- **WHOIS** is a **protocol** used to *access databases containing information about internet resources* like domain names, IP addresses, and autonomous systems. It is often described as a "phonebook for the internet."

- ![[Pasted image 20250917085341.png]]


- **Domain Name:** The specific domain registered.
  
- **Registrar:** The company through which the domain was registered.
  
- **Contact Information:** This includes the names and contact details for the registrant, as well as administrative and technical contacts.
  
- **Dates:** The dates of creation, last update, and expiration.
  
- **Name Servers:** The servers that translate the domain name into an IP address.


## Importance for Cybersecurity (Web Reconnaissance)

- **Identifying Key Personnel:** It can reveal names and contact information of individuals, which can be used for **social engineering** or **phishing attacks**.
  
- **Discovering Network Infrastructure:** Provides technical details like name servers and IP addresses, which can help in identifying potential **vulnerabilities** or entry points.
  
- **Historical Data Analysis:** Historical records can be analyzed to track changes in a target's digital presence over time.
