## Web Archives

- It is a **digital archive** of the World Wide Web, founded by the non-profit organization Internet Archive.

- [Link](https://web.archive.org/)

- It has been archiving websites since 1996, creating historical snapshots (captures) of how they appeared at various points in time.

- This allows users to view **past versions** of a website, including its design, content, and functionality.
![[Pasted image 20250922102403.png]]


## How it Works

- The process relies on **automated web crawlers** that systematically browse the internet, downloading copies of webpages and their associated resources (HTML, CSS, JavaScript, images).

![[Pasted image 20250922102600.png]]

- The operation can be broken down into three steps:
    1. **Crawling:** Bots follow links and download webpage content.
       
    2. **Archiving:** The downloaded content is stored and timestamped, creating a historical snapshot.
       
    3. **Accessing:** Users can search for a URL and select a specific date to view the archived version.


- The frequency of captures for a given website varies depending on its popularity and how often it is updated.

- The archive does not capture every page on the internet, prioritizing sites of cultural or historical value. Website owners can also request to be excluded.


#### Importance for Web Reconnaissance

- The Wayback Machine is a significant tool for Open Source Intelligence (OSINT) gathering.

- **Uncovering Assets:** It can reveal old pages, files, directories, or subdomains that are no longer linked on the live site but may still exist, potentially exposing vulnerabilities or sensitive information.


- **Tracking Changes:** Comparing different snapshots helps identify changes in a website's structure, technology stack, and content over time.


- **Stealth:** Using the Wayback Machine is a passive reconnaissance technique because it does not involve direct interaction with the target's live servers, making it difficult to detect.
